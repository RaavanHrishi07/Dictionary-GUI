# Dictionary GUI 📖

A Python-based desktop dictionary application built using Tkinter. Search English words and explore their definitions, pronunciation, examples, synonyms, and antonyms through a free dictionary API.

## ✨ Features

- Search English word meanings.
- Display multiple definitions.
- Show parts of speech.
- Display pronunciation and phonetic information.
- Show example sentences.
- Display available synonyms and antonyms.
- Search using the Enter key.
- Clear search functionality.
- Recent search history.
- Scrollable dictionary results.
- Background API requests to keep the interface responsive.
- Handles invalid words, connection errors, and request timeouts.

## 🛠️ Technologies Used

- Python 3.11
- Tkinter
- Requests
- Free Dictionary API

## 📋 Requirements

- Python 3.11 or later
- Tkinter
- Requests

## 🚀 Installation

Clone the repository:

```powershell
git clone https://github.com/RaavanHrishi07/Dictionary-GUI.git
```

Navigate to the project directory:

```powershell
cd Dictionary-GUI
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## ▶️ Run the Application

```powershell
python dictionary.py
```

## 🌐 API

This application uses the Free Dictionary API:

https://dictionaryapi.dev/

No API key is required.
